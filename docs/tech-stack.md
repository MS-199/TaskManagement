# 技術スタック・システム構成

[要件定義書](requirements.md)の詳細ドキュメント。

## システム構成方針

- **フロントエンド + バックエンドAPI + データベース**の構成とする。
- フロントエンド: **React + TypeScript**(Next.jsは本プロジェクトでは対象外)、ドラッグ&ドロップは **@dnd-kit** を使用。
- バックエンド: **Java + Spring Boot** によるREST APIサーバーを用意し、フロントエンドからのリクエストを受けてデータベースを読み書きする。
- データベース: **PostgreSQL** を採用する。DBサーバーとして稼働させ、永続的なデータストアとする。
- プロジェクト構成: **Gradle** をビルドツールとし、`backend/`(Spring Boot)と`frontend/`(React)を分けたモノレポ構成とする。
- データはすべてデータベースに保存され、永続化する(ブラウザのlocalStorageは使用しない)。
- 認証機能、複数ユーザー対応、デプロイ用CI/CDパイプラインは本バージョンでは扱わない(利用者は引き続き1人を想定)。

## データの流れ

```
┌───────────────┐   リクエスト(作成/更新/削除/取得)   ┌───────────────┐   読み書き   ┌───────────────┐
│  ブラウザ       │ ───────────────────────────────▶ │  バックエンドAPI │ ──────────▶ │  データベース    │
│ (React画面)     │ ◀─────────────────────────────── │ (Spring Boot)  │ ◀────────── │ (PostgreSQL)   │
└───────────────┘        レスポンス(データ)           └───────────────┘   結果      └───────────────┘
```
- 画面上での操作(ボード/リスト/カードの作成・編集・削除・並び替え)は、その都度APIを通じてデータベースに反映される。
- 画面を開いたとき・再読み込みしたときは、APIを経由してデータベースから最新の内容を取得して表示する。
